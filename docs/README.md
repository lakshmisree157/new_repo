# Project scaffold for Pet Adoption

This repository contains a scaffold supporting multiple login roles (admin, adoption center, adopter) and a placeholder `ml_model` for future compatibility matching.

Folders:
- `frontend` - static/front-end code (React-ready)
- `backend` - Node.js + Express app
- `database` - MySQL schema and MongoDB models
- `ml_model` - scripts, datasets, and models
- `config` - env & DB connection helpers
- `tests` - unit/integration tests
- `public` - static assets
- `docs` - documentation

Use `config/.env.example` to create your `.env`.
